## For T022-T028
- Scripts: from the repo root, `SHIPYARD_SLOT=<n> scripts/dev/start-stack.sh`; in an agent worktree the slot is
  mandatory (error otherwise). Order: stop slot stack, refuse (exit 1, names each busy port) if a slot port is in
  use, wipe `$SHIPYARD_DATA_DIR`, start, wait up to 30 s per service for `/openapi.json`, on failure print the log
  tail and stop everything. Pid and log files: `$SHIPYARD_DATA_DIR/<service>.pid` and `.log`.
- `stop-stack.sh` tolerates pid files of exited processes (removes them, exit 0), and only signals a pid whose
  command line contains `uvicorn` (guards against pid reuse). T028 can stop one service by killing its pid file
  entry and later call stop-stack/start-stack without errors (tested).
- `ports.sh` is sourced; it also exports `*_PORT`, the four `*_DATABASE_URL` defaults and a `service_port` function.
- `check_shared_copy.py` takes `--self-test` and `--root DIR`; it reports "not created yet" until T022 adds `shared/`.
- Service `app/main.py`, `tests/test_main.py`, `pyproject.toml`, `uv.lock` now belong to T023-T026; `static/` to T027.
- The CI step uses `enable-cache` with `cache-dependency-glob` on the service's `uv.lock`.
