# T027 hand-off

Dashboard UI: `services/dashboard/static/{index.html,app.js,style.css}`. Plain HTML and JavaScript, no build step, no
framework, no external host. `index.html` is served at `/`, the assets at `/static/app.js` and `/static/style.css`.

## Views (four sections, each a semantic table with a heading)
- Builds: `GET /builds?limit=200`. Pipeline, build ID, status, started, finished, steps (`name: status` list), failure.
- Failures: `GET /builds?status=failed&limit=200`. Same columns. The Failure column says `step "<name>" failed` or
  `artifact upload failed` (the `failure_reason`, #120).
- Artifacts: `GET /artifacts?limit=200`. Name, version, checksum, size (bytes), build ID, uploaded. Artifacts of failed
  builds are listed like any other (#131 option a).
- Releases: `GET /releases?limit=200`. Artifact (`name vN`), status, requested by/at, decided by/at. No promotion shown.
- A null field shows a dash. Status is text (colour is extra). Empty and error states are per section; on a failed
  refresh the last good rows stay and a red message says the data may be stale.
- No buttons, forms or write requests; only the three read endpoints of the dashboard itself; all event data goes in with
  `textContent`.
- Refresh: every 5 s (`REFRESH_MS` in app.js), no page reload; a refresh is skipped while the previous is in flight.
- Narrow widths: the page does not scroll sideways; each table scrolls inside a focusable region.
- Limit is 200 (contract maximum); no paging UI, so more than 200 items per view are not shown.
- `<link rel="icon" href="data:,">` stops the favicon 404 console error.

## Smoke test
`export SHIPYARD_SLOT=5; scripts/dev/start-stack.sh`, then seed with POST /events on port 18053 (T023 recipe; see
`docs/tasks/T023.md`): passed build, step-failed build, build failed by upload, build.finished without build.started
(null started_at), a running build, two artifacts, releases pending/approved/rejected-without-request. Open
`http://127.0.0.1:18053/` in Chrome. Note the contract caps names at 100 characters. Stop with `stop-stack.sh` and delete
`/tmp/shipyard/slot5`.
